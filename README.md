# React 实战学习

交互式中文 React 教程：课程 · Demo · 测验 · 进度 · 模拟全栈工坊。

**在线：** 部署后见 GitHub Pages `https://xiaoqianran.github.io/learning-react/`  
**仓库：** https://github.com/xiaoqianran/learning-react  
**姊妹项目：** [learning-vue3](https://github.com/xiaoqianran/learning-vue3)

---

## 功能

| 模块 | 说明 |
|------|------|
| 21 节课程 | 基础 → 进阶 → 全栈准备 → 实训 → 工程化 |
| 交互 Demo | 每课动手 |
| 测验 / 错题本 | 巩固 |
| 学习中心 | 打卡、路径进度 |
| 全栈工坊 | 模拟登录 + 笔记 CRUD + 闯关 |
| 沙箱 / 速查表 | 快速练习与复习 |

## 本地运行

```bash
npm install
npm run dev      # http://127.0.0.1:8080
npm run build
npm run typecheck
```

GitHub Pages：`npm run build:pages`（`GITHUB_PAGES=true`，base=`/learning-react/`）
